# 🤖 بوت البحث — ويت أنمي (search-bot)

بوت تليجرام للبحث في موقع **ويت أنمي** وتصفح الحلقات، مع:

- 🔍 بحث باسم الأنمي مع نتائج وأزرار تنقل.
- 📺 تصفح حلقات أي أنمي (مجزأة 20 حلقة في الصفحة).
- 🎬 مشاهدة الحلقة عبر صفحة مشاهدة خاصة (مشغل فقط، خلفية سوداء) — سيرفر yonaplay يُعرض بمشغلاته البديلة (Google Drive / Mega / 4shared بجودتي HD وFHD).
- ⬇️ روابط تحميل مباشرة بكل الجودات (SD / HD / FHD).
- 📤 إرسال الفيديو داخل تليجرام مع اختيار الجودة (Google Drive HD/FHD أو ok.ru) — حتى 45 ميجا افتراضيًا، وحتى **2 جيجا** عند تفعيل `TG_API_ID`/`TG_API_HASH`.
- 📦 **تحميل موسم كامل** أو 🎯 **مدى حلقات** كفيديوهات متتالية داخل تليجرام من أي مصدر متاح (Google Drive / Mega / ok.ru / gofile) — مع فحص الجودات المتاحة (FHD / HD / SD)، وزر إلغاء فوري، وملخص نهائي مفصّل لكل حلقة.
- 🔔 **متابعة أنمي**: إشعار تلقائي عند نزول حلقة جديدة (فحص دوري كل `FOLLOW_CHECK_HOURS` ساعة).
- ⭐ **مفضلة** لحفظ أنمياتك والوصول لها بسرعة من `/favorites`.
- 🆕 **آخر الحلقات** المنزلة على الموقع من زر في رسالة `/start`.
- 🛡 أوامر أدمن (`/stats` `/ban` `/unban` `/broadcast`) واشتراك إجباري بقناة — كلها اختيارية عبر متغيرات البيئة.

## 🔑 متغيرات البيئة (Environment Variables)

| المتغير | مطلوب؟ | الشرح |
|---------|--------|-------|
| `BOT_TOKEN` | ✅ نعم | توكن البوت — تحصل عليه من بوت [@BotFather](https://t.me/BotFather) في تليجرام (أرسل `/newbot` واتبع الخطوات). |
| `BASE_PUBLIC_URL` | ✅ نعم | رابط الدومين العام لمشروعك في Railway، مثال: `https://search-bot-production.up.railway.app` (بدون `/` في النهاية). يُستخدم لبناء روابط صفحات المشاهدة. |
| `PORT` | ❌ لا | المنفذ الذي يعمل عليه سيرفر صفحات المشاهدة. الافتراضي `8080`، وRailway يمرّره تلقائيًا فلا حاجة لتغييره. |
| `WATCH_SECRET` | ❌ لا | كلمة سر لتوقيع روابط المشاهدة (حتى لا يستخدمها الغرباء). إن تركته فارغًا يُستخدم توكن البوت تلقائيًا. |
| `TG_API_ID` | ❌ لا | معرف API من [my.telegram.org](https://my.telegram.org) ← **API development tools**. مع `TG_API_HASH` يفعّل سيرفر Bot API محلي داخل الحاوية فيرتفع حد إرسال الفيديو إلى **2 جيجا** بدل 50 ميجا. |
| `TG_API_HASH` | ❌ لا | مفتاح API من نفس الصفحة — يجب تعبئته مع `TG_API_ID` معًا، وإلا يعمل البوت بالوضع القياسي. |
| `ADMIN_IDS` | ❌ لا | معرفات تليجرام للأدمن مفصولة بفواصل — تفعّل أوامر `/stats` `/ban <id>` `/unban <id>` `/broadcast`. |
| `FORCE_SUB_CHANNEL` | ❌ لا | قناة اشتراك إجباري (`@channel` أو معرف `-100…`) — فارغ = معطّل. ⚠️ يجب أن يكون البوت **أدمن في القناة** حتى يتمكن من التحقق من العضوية. |
| `DATA_DIR` | ❌ لا | مجلد تخزين بيانات البوت (مفضلة/متابعات/إحصائيات). الافتراضي مجلد temp. ⚠️ **على Railway التخزين مؤقت** — تُفقد المتابعات والمفضلة عند إعادة النشر الكاملة. |
| `FOLLOW_CHECK_HOURS` | ❌ لا | عدد الساعات بين كل فحص للحلقات الجديدة (المتابعات). الافتراضي `6`، أدنى قيمة `1`. |
| `BATCH_MAX_EPS` | ❌ لا | أقصى عدد حلقات في دفعة تحميل موسم واحدة. الافتراضي `24`. |
| `BATCH_GLOBAL_MAX` | ❌ لا | أقصى عدد دفعات مواسم تعمل في نفس الوقت (لكل المستخدمين). الافتراضي `2`. |

## 🚀 خطوات النشر على Railway (للمستخدم غير الخبير)

1. **أنشئ البوت وخذ التوكن**: من تليجرام افتح [@BotFather](https://t.me/BotFather)، أرسل `/newbot`، اختر اسمًا ومعرّفًا، وانسخ التوكن الذي يعطيك إياه (شكله مثل `123456:ABC-DEF...`).
2. **ارفع الكود على GitHub**: ارفع هذا المستودع (repo) على حسابك في GitHub.
3. **افتح مشروعًا جديدًا في Railway**: من [railway.app](https://railway.app) اضغط **New Project** ثم **Deploy from GitHub repo** واختر المستودع.
4. **حدّد مجلد البوت**: في إعدادات الخدمة (Settings) ضع **Root Directory** = `search-bot` حتى ينشر هذا البوت فقط.
5. **أضف المتغيرات**: من تبويب **Variables** أضف:
   - `BOT_TOKEN` = التوكن الذي نسخته من BotFather.
   - `BASE_PUBLIC_URL` = اتركه مؤقتًا (سنكمله في الخطوة التالية).
6. **ولّد الدومين العام**: من **Settings → Networking** اضغط **Generate Domain**. انسخ الرابط الناتج (مثل `https://xxx.up.railway.app`) وأضفه في المتغير `BASE_PUBLIC_URL` ثم أعد النشر (Redeploy).
7. **جرّب البوت**: افتح بوتك في تليجرام وأرسل `/start` ثم ابعت اسم أي أنمي 🎉

> ✅ للتأكد أن السيرفر يعمل: افتح رابط الدومين في المتصفح، يجب أن ترى كلمة `OK`.

## 🛠 التشغيل محليًا (للمطورين)

```bash
cd search-bot
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env   # ثم املأ القيم
python bot.py
```

البوت يعمل بطريقة **polling** (لا يحتاج webhook)، ويشغّل معه سيرفر FastAPI لصفحات المشاهدة على نفس المنفذ `PORT`.

## ⚠️ ملاحظات مهمة

- **حد إرسال الفيديو**: تليجرام يسمح للبوتات بإرسال حتى **50 ميجا** عبر Bot API القياسي (نستخدم هامش أمان 45 ميجا). عند تعبئة `TG_API_ID` و `TG_API_HASH` يشتغل داخل الحاوية سيرفر **Bot API محلي** (telegram-bot-api) فيصبح الحد **2 جيجا**. بدونهما تظهر للفيديوهات الكبيرة أزرار المشاهدة والتحميل بدلًا من الإرسال.
- **«إرسال الفيديو هنا»** يعرض قائمة جودات: روابط **Google Drive** (HD / FHD) المستخرجة من سيرفر yonaplay + **ok.ru** بأعلى جودة. الميزة أفضل جهد (best-effort) — إن تعذّر التجهيز جرّب جودة أخرى أو استخدم المشاهدة/التحميل.
- **صفحات المشاهدة** تبث من سيرفرات طرف ثالث (Google Drive وMega و4shared وok.ru وغيرها)، فقد يتوقف بعضها أحيانًا — جرّب سيرفرًا آخر من القائمة، أو رابط «فتح في تاب جديد» أسفل صفحة المشاهدة.
- **تحميل الموسم**: من صفحة حلقات أي أنمي اضغط «📦 الموسم كامل» أو «🎯 مدى حلقات» (اختر أول ثم آخر حلقة)، اختر الجودة من المتاح فقط، وأكّد — تُرسل الحلقات فيديو تلو الآخر مع زر ❌ إلغاء فوري وملخص نهائي. الحلقات الأكبر من الحد تُرسل روابط تحميلها بدلًا من الفيديو والتحميل يكمل. المصادر: **Google Drive / Mega / ok.ru / gofile** (ملفات gofile تكون ZIP ويُفك ضغطها تلقائيًا) — أما باقي الهوستات (mediafire / workupload / send...) فتبقى كروابط تحميل يدوية فقط.
- **حفظ البيانات**: المفضلة والمتابعات والإحصائيات تُحفظ في `DATA_DIR` — على Railway نظام الملفات **مؤقت** فتُفقد هذه البيانات عند إعادة النشر الكاملة (full redeploy). أما عند التشغيل على VPS فثبّت `DATA_DIR` على مجلد دائم.
- **الاشتراك الإجباري**: عند ضبط `FORCE_SUB_CHANNEL` لن يتمكن غير المشتركين من استخدام البوت — وتذكّر: **البوت يجب أن يكون أدمن في القناة** وإلا لن يستطيع التحقق من العضوية (في هذه الحالة يعمل البوت بشكل طبيعي مع تسجيل خطأ في السجل).
